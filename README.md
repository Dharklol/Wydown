# Wydown

Wydown is an experimental, independently accounted portfolio research and risk-management framework.

**Current status:** architecture/specification stage; no production broker integration and no live trading enabled.

The initial isolated pilot mandate is $5,000 with a 30% peak-to-trough **planning** drawdown threshold (not a guaranteed loss cap). Research, paper, and live ledgers must remain separate.

See [RFC-001](https://github.com/Dharklol/Wydown/issues/1) and the linked specification issues before proposing production code. The initial CI pull request will establish guarded changes; thereafter, do not push directly to `main`.
